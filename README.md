# inhLLm V2 · Ollama GGUF

Экспериментальная компактная языковая модель на архитектуре GPT-2, реализованная и обученная в проекте inhLLm V2. Репозиторий предназначен для **готовых GGUF-весов**, которые можно быстро импортировать в Ollama на Linux или macOS.

> **Важно:** это экспериментальная модель продолжения текста, а не обученный чат-ассистент. Возможны бессвязные ответы, выдуманные слова и повторения. Не рассчитывайте на фактическую точность.

## Быстрая установка на Linux / macOS

Требуются `git` и запущенная [Ollama](https://ollama.com/).

### Шаг 17 500

```bash
STEP=17500
DEST="$HOME/models/inhllm-v2-$STEP"
git clone --depth 1 --single-branch --branch "inhllm-v2-$STEP" \
  https://github.com/tranzistrina/inhllm-v2.git "$DEST"
ollama create "inhllm-v2:$STEP" -f "$DEST/Modelfile"
ollama run "inhllm-v2:$STEP" "Однажды в далёком городе"
```

### Шаг 14 700

```bash
STEP=14700
DEST="$HOME/models/inhllm-v2-$STEP"
git clone --depth 1 --single-branch --branch "inhllm-v2-$STEP" \
  https://github.com/tranzistrina/inhllm-v2.git "$DEST"
ollama create "inhllm-v2:$STEP" -f "$DEST/Modelfile"
ollama run "inhllm-v2:$STEP" "Однажды в далёком городе"
```

Команды работают **после публикации GGUF и `Modelfile` в соответствующих ветках**. Наличие ветки без весов ещё не позволяет запустить модель.

## Проверка без случайного семплирования

```bash
curl -fsS http://localhost:11434/api/generate \
  -H 'Content-Type: application/json' \
  -d '{"model":"inhllm-v2:17500","prompt":"Однажды в далёком городе","raw":true,"stream":false,"options":{"temperature":0,"top_k":1,"repeat_penalty":1.0,"num_ctx":256,"num_predict":60}}' \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["response"])'
```

Для шага 14700 ранее было получено совпадение 60-токенной greedy-генерации между нативным CUDA-инференсом и Ollama на Mac. Это проверка одного запроса, а не доказательство полной совместимости всех сценариев. Для шага 17500 отдельная проверка паритета пока не документирована.

## Характеристики

- Архитектура: GPT-2-подобный decoder-only Transformer.
- Параметры: 5 853 184; ширина 256; 6 блоков; 8 attention-heads.
- Контекст: 256 токенов.
- Токенизатор: INHBPE2, словарь 4096 токенов.
- Формат весов: GGUF, FP32; размер около 27–28 МБ.
- Назначение: исследование обучения небольших языковых моделей, а не выполнение инструкций.

## Повторная установка

Если модель с тем же именем уже существует, `ollama create` обновляет запись. Оригинальные GGUF остаются в клонированном каталоге. Для просмотра установленных моделей: `ollama list`.
